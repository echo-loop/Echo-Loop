# 今日打卡分享

仅登录用户可用。自动打卡事件触发后台准备：获取今日模板、下载背景和头像、读取统计并生成 1080×1440 PNG。图片默认只保留在当前账号、当前学习日的内存中。

## 展示规则

- 返回学习首页或回到前台时检查一次；只有图片已下载并渲染成功才打开。
- 检查时未就绪就跳过，不在后台完成时补弹。手动点击未就绪时只 toast，并复用准备任务或重试失败任务。
- 页面必须可见、应用在前台且没有其它弹窗或引导。展示前检查账号、日期和可见性；自动判断只读已落地本地标记，不等待网络同步。
- 成功展示后记入 `learning.dailyCheckInShareShownDate`，通过现有偏好同步跨平台去重。同步失败时使用本机记录，离线或同时打开不保证全账号严格只展示一次。
- 登录、换号、登出及切库取消旧代次；跨日释放旧卡。统计变化时复用当天背景；仅实际绘制内容变化时重新合成，刷新期间保留有效成品，弹窗持有独立预览快照。

## 修改卡片

唯一合成函数为 `lib/features/daily_goal_check_in/data/daily_check_in_share_image.dart` 中的 `generateDailyCheckInShareImage`。它返回 PNG 字节和已渲染预览，弹窗不需要再次解码或截图。修改布局、字体、Logo、统计排版均从此入口维护。

- 后端返回背景 URL、上下文字颜色和 word/sentence 文案。复用 today、random、shares 三个既有公开 API；客户端以登录状态限制功能。
- 本地日期、总时长、听说明细和连续学习天数使用学习统计；今日模板请求携带本地日历日（`date=YYYY-MM-DD`），服务端按该日期选卡并回显，客户端校验回显一致后才缓存。
- Logo 固定为透明的 `app-icon-1024-alpha.png`，名称固定 `Echo Loop`。
- 英语界面的单词/句子卡片不绘制译文，保留英文原文与单词音标；中文界面按母语设置选择译文。切换界面语言重新合成，继续复用背景和头像缓存。
- 副标题按界面语言选择「英语听说 E 筋经」或「Listen. Speak. Grow.」。
- 二维码按现有中国用户判定选择 `assets/qr/www.echo-loop.cn.png` 或 `www.echo-loop.top.png`，与界面语言独立。
- 换卡时保留原预览，只有新卡全部准备成功才替换；没有其它模板时不重新生成原图。

## 保存、分享与清理

iOS/Android 通过 gal 保存到系统相册，只在点击保存时请求添加照片权限；macOS 通过系统文件对话框保存。系统分享通过 share_plus，提供 iPad/macOS 锚点；分享计数失败不重试、不阻断分享。

分享文件写入临时目录 `daily_check_in_share_export_*`，同一图复用文件。每次分享更新 `.last_used` 租约，按最后使用时间保留 24 小时，避免 AirDrop 尚未读取就删除文件。启动、回前台、导出前及设置页清缓存均清理过期文件；用户相册和自行保存的文件不属于清理范围。

## 验证

相关测试覆盖准备与渲染门槛、手动 toast、不补弹、换卡失败保留原图、账号切换、跨日丢弃响应、API 契约、同步等待和冲突合并、分享租约清理。图片渲染测试在 `build/test_artifacts/` 输出单词及句子卡片，供排版检查。

原生相册权限和系统分享接收方仍需 iOS/Android 真机确认；macOS 构建及 iOS CocoaPods 依赖安装可在本地验证。

## 性能与缓存（2026-11-09）

- 首次准备没有成品时仍使用准备中状态；已有当天成品时使用 `isRefreshing` 表达后台工作，成功后原子替换，失败保留旧图。首次准备完成不补弹。
- 合成只读当前账号资料快照，不等待 profile 网络请求；头像按账号和 URL 在后台加载，缺失时先画昵称首字，成功后更新。相同 URL 下载失败不会随统计刷新重复请求；URL 变化、跨日、换号或清缓存后可重新加载。
- 模板及背景当天复用；固定 Logo、二维码字节和字体加载复用。成品比较日期、模板、展示分钟、连续天数、昵称、头像版本、语言和地区；显示结果不变直接复用 PNG 与预览。连续变化只处理最新输入，过期生成结果不发布。
- 解码缓存每种用途只保留一份当前资源；背景覆盖1080×1440，头像54px、Logo80px、二维码106px，保持比例且不放大源图。借用独立句柄，替换/清理不会破坏正在生成或已打开的预览；跨日、换号、数据库变化释放用户动态缓存；语言/地区变化只让合成成品失效，继续复用背景、头像与固定资源。
- 自动去重不在展示路径等待云端；后台同步维持最终一致性，尚未同步的其它设备记录仍可能导致重复展示。
- `DailyShare` 日志分别记录解码缓存命中、解码、Canvas 绘制、栅格化、PNG编码、总准备及自动跳过原因。

性能采样测试：`test/features/daily_goal_check_in/data/daily_share_image_performance_test.dart`，同一测试引擎使用1080×1440合成背景及真实Logo/二维码。一次Debug测试冷样本304/222/205ms，中位222ms；暖样本213/204/147ms，中位204ms。暖缓存Canvas绘制2～5ms，栅格化43～78ms，PNG编码98～139ms。该结果不代表生产设备或真实照片背景；Profile/Release实机的暖重绘200ms目标仍需测量。已有成品打开及无视觉变化更新均不调用生成器、不等待网络。

本次验证：160项分享、偏好、首页和设置相关测试通过，定向分析无问题。系统Vision在句子/单词生成图中均识别到 `https://www.echo-loop.cn/` 二维码；真机扫码与Profile/Release性能仍需设备确认。

## 今日背景跨启动复用（2026-11-09）

今日模板与背景是公开资源，独立于用户资料和界面语言，保存在系统缓存目录的 `daily_check_in_share_backgrounds` 专用目录。按本地学习日期保留一份选中模板和背景；同日重启先读磁盘，语言变化只重新合成，不请求today接口、不下载背景或已有头像。内存和磁盘都未命中、缓存损坏、系统回收或用户主动清缓存时，才重新获取。并发首次准备合并为一次请求。

`DailyShareBackgroundRepository`负责内存与磁盘读取、远程资源获取；`DailyShareBackgroundStore`只负责文件持久化。清单最后原子提交，写入/读取/删除串行，使用SHA256、20MB和图片尺寸校验恢复损坏缓存。跨日读取/午夜到期清理旧背景；目录仅保留当前清单和图片，不积累历史。设置页清缓存同时清理内存资源与持久文件，旧请求不能重新写回。

「换一个」是显式请求其它模板，仍需网络下载新背景；只有渲染成功才记住选择，重启及切换语言继续使用选中的背景。背景缓存不含账号、头像、昵称、统计或最终合成PNG；用户成品继续按账号/日期隔离，应用重启后使用本地背景与当前统计重新合成。

验证：106项相关回归通过；14项Provider测试包含语言切换不重复下载背景和头像。真实文件测试覆盖跨实例恢复、损坏回退、过期清理、原子替换、尺寸/大小限制、并发合并和清缓存防旧写回。
