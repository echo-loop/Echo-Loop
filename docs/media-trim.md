# 媒体剪辑

## 行为

已下载材料的更多菜单提供「剪辑」，可以把一段音频或视频切成多个独立的新材料。
原材料、字幕、收藏和学习记录保持不变。新材料只保存到本地合集（播客和社区合集
仍由各自来源管理），没有播客 GUID、社区 ID 或原下载地址，`importSourceType`
为 `trimmed`。

### 编辑交互

- **时间轴**（参照系统相册视频裁剪）：显示整段波形、全部片段（带序号）、当前片段的
  两端把手和播放头。
  - 选中片段后播放头只能在片段内移动；点按其它片段即选中它并定位到点按处，点按所有
    片段之外则取消选中、自由定位（桌面端也可按 Esc）。
  - 把手长在片段外侧，框内露出的正好是片段内容，播放头停在起点 / 终点时贴着把手
    内沿；抓把手时边界保持与手指的相对距离，不会一抓就跳。
  - 拖动把手靠近其它片段的起点 / 终点时磁吸对齐（鼠标 6px、触摸 10px 内），便于首尾
    无缝衔接；吸上时轻震一次（`HapticFeedback.selectionClick`，桌面无震动），并画一条
    被吸附片段颜色的对齐线；继续拖出磁吸范围即脱开。
  - 播放头可直接拖动（与把手相邻时，按在片段内侧或顶部序号行抓播放头，按在把手上
    抓把手）；未放大时在空白处拖动也直接拖播放头，放大后拖动空白处平移，松手按 iOS
    滚动的摩擦系数惯性滑动，按下即停住且这次轻点不定位。
  - 拖动把手时隐藏播放头，松手后播放头停在刚调整的一端；一端不能越过另一端，拖过头
    停在最短长度（有字幕时为片段内首 / 末一句），不会整段跳走。
  - 双指捏合、触控板捏合或 Ctrl/⌘ + 滚轮缩放，放大后滚轮平移；选中片段时左下角
    显示「起 – 止 · 时长」（图标用片段颜色），点按放大到该片段；播放时播放头离开视口自动翻页；
    重复点选当前片段也会把它滚入视口。有字幕时底部显示句子位置条。
- **播放**：选中片段时播放 / 试听只播该片段——没动过播放头从片段起点播，手动移到
  片段内某处则从该处播，已播到末尾再播则回到起点；未选中时从播放头自由播放。
  试听单句是唯一可以让播放头离开选中片段的操作。
- **视频画面**：默认收起，把高度留给时间轴和片段；播放栏右侧的视频图标展开 / 收起
  （收起时图标带斜线）。音频材料不显示该按钮。
- **片段列表**：按起点排序，标题就是保存时的名称（自定义名称，或按排序位置生成的
  `原名 · 01`），与重命名弹窗一致；默认名过长时只省略原名部分、保留序号。界面不再
  另起「片段 N」这类叫法，避免和保存结果对不上。选中片段的起止编辑左右并排。当前片段就地展开起止编辑：提前 / 推后（有字幕按整句，无字幕按
  100ms，长按连续微调）、点时间手动输入。任何一端调整后播放头停到该端。
- **字幕列表**（只读）：点句子试听并把播放头定位到该句，再点「新片段」即从这句开始
  建段；左侧色条标出句子所属片段。不再提供每行的「起 / 止」按钮和「设为
  播放位置」按钮：边界统一用时间轴把手和提前 / 推后调整，控件少、含义单一。
- **新片段**：在空白处（不被任何片段覆盖的区间）新建，可连续点。
  - 从播放头往后找：播放头在片段内时从该片段末尾起，因此连续点会依次往后填空白；
    后面没有空白时回到开头。
  - 默认 2 分钟，空白不足 2 分钟用整段空白，但不短于 10 秒（材料本身更短时以全长为
    下限）；播放头后剩余太短时贴着这段空白的末尾建段。有字幕时只取完整句子，累积到
    不超过 2 分钟，不足 10 秒时向前补句。
  - 找不到足够长的空白时用顶部 toast（`showAppToast`）提示「先缩短或删除已有片段」。
- **片段配色**：按片段序号循环使用 6 色（蓝、玫红、青、琥珀、紫、绿，冷暖交替），相邻
  片段一定不同色，自动分段同样适用；时间轴区间与波形、序号、片段卡片、字幕色条和
  时间轴下方范围标签的图标共用同一颜色。颜色跟随序号，插入片段后序号与颜色一起顺延。亮 / 暗
  主题各一套（`widgets/media_trim_clip_colors.dart`）。
- **自动分段**：按 1 / 2 / 3 / 5 / 10 分钟切整段并替换现有片段，只列出比材料短的段长；
  材料不超过 1 分钟时说明无需自动分段，不能应用。有字幕时按整句累积，
  每段不超过目标；无字幕时等分。末段不足目标三成时并入前一段。
- **桌面快捷键**：空格 播放 / 暂停，I / O 以播放位置设起 / 终点（无选中时新建），
  N 新片段，← / → 后退 / 前进 1 秒，Esc 取消选中（界面不单独展示说明）。
- 布局：宽屏（≥960×520）左侧为预览、播放栏、时间轴和字幕，右侧为片段列表；
  窄屏固定时间轴，下方用「片段 / 字幕」标签页；矮窗口整页滚动。

### 字幕边界规则

字幕只读。时间重叠的字幕合并为不可拆分的单元，片段起止只能落在单元之间的空隙。
起止会向空隙外扩 300ms 余量吸收时间戳误差、避免切掉首尾音节，但不越过空隙中点，
因此相邻片段恰好衔接。新材料的句级和词级时间戳只减去片段起点，不做校准或缩放；
只保留完整落在片段内的句和词。只有画面字幕或尚未导入的内嵌字幕轨按无字幕处理。

### 保存

保存弹窗选择已有本地合集或新建合集（默认入口所在的本地合集，否则新建
`原名 · 片段`）。材料来自播客或共享合集（入口合集不是本地合集，或材料带播客 GUID /
社区 ID）时，弹窗顶部提示这类合集由来源维护、片段只能保存到本地合集。保存时显示进度遮罩，可取消。成功后若保存到入口合集则返回，
否则跳转到目标合集。内容与库中已有材料完全相同的片段不重复入库，而是把已有材料
加入目标合集，并在提示中说明数量；同一批里内容相同的片段只保留一份。

## 实现

`lib/features/media_trim/`：

| 文件 | 职责 |
| --- | --- |
| `media_trim_clip.dart` | 纯领域逻辑：片段、失败原因、句子单元、吸附 / 微调 / 联动、自动分段、校验、字幕平移 |
| `media_trim_processor.dart` | FFmpeg 边界：探测、精确重编码、波形代理音轨；无状态，取消令牌只取消本任务的原生会话 |
| `media_trim_repository.dart` | 数据访问：读取原字幕、单事务发布整批材料（含去重复用）、清理未发布目录 |
| `media_trim_exporter.dart` | 保存编排：逐段编码到独占任务目录、校验、指纹、调用仓库发布、失败清理 |
| `media_trim_waveform_loader.dart` | 波形加载：与字幕编辑共用 `waveforms/{id}.wave` 缓存，先写临时文件再改名 |
| `media_trim_editor_controller.dart` | 编辑状态 Notifier（autoDispose.family）：播放、试听竞态、片段编辑、保存进度 |
| `media_trim_screen.dart`、`widgets/` | 页面布局、时间轴、片段面板、字幕列表、对话框 |

- 剪辑页独占一个 `MediaPlayerBackend`，不接入学习统计或系统媒体会话；进入时暂停
  随心听等其它正在出声的播放链路。试听请求用递增代号作废过期的异步步骤。
- 音频输出 AAC/M4A，视频输出 H.264 + AAC/MP4，全部精确重编码，不用关键帧流复制。
  Apple 使用 VideoToolbox 并允许系统软件编码（见 troubleshooting 7.52），Android 使用
  MediaCodec。视频码率取原视频流码率并钳在 0.8–12 Mbps，未知时 4 Mbps。产物生成后
  校验可解码且时长误差不超过 150ms。FFmpeg minimal 固定到 3.6.7。
- 每批产物写入 `audios/trimmed/<taskId>` 或 `videos/trimmed/<taskId>`，各片段使用新
  UUID 和实际文件 SHA256。全部生成并校验后单事务写入媒体、字幕和合集关联；提交前
  失败或取消删除整批目录。启动清理与发布走同一数据库事务串行，保留所有被引用
  （含软删）的文件，并跳过当前进程内的活动任务。
- 时间轴视觉：每个片段为自己颜色的浅色圆角块，片段内波形用该色（选中为实色）；选中
  片段为同色外框 + 外侧实心把手（带方向箭头）；播放头为带投影的白色圆头竖条（参照
  系统相册，不画顶部圆点以免盖住序号）；片段序号居中放在片段上方，波形为圆头竖条。
- 图标线宽统一约 1.67px：Material 线条图标一律 20px；`split.svg`、`arrow-range.svg`
  改为描边路径（线宽按 20px 渲染换算），`video-2.svg` 以 22px 渲染；收起画面的斜线同宽。
- 时间轴自行绘制，波形采样经 `lib/utils/waveform_samples.dart` 读取，规避
  just_waveform 16 位数据错位问题（见 troubleshooting 7.54）。
- 关键路径写 `MediaTrim` 日志：加载、波形缓存 / 提取、片段新建 / 删除 / 边界调整 /
  自动分段、保存开始 / 每段编码耗时与大小 / 发布结果 / 失败与取消、启动清理。
- 不提供后台持续导出或进程重启后恢复草稿；输出不保留额外字幕、章节和多音轨，
  不烧录播放器遮罩；原格式无法编码时明确报错。
