# 今日打卡分享性能优化计划

**目标：** 当天已有图片时立即可展示和分享；统计刷新不清空成品，不等待资料网络请求，避免没有视觉变化的重绘。
**执行方式：** 按下列顺序逐项实施，使用现有架构；实现已完成；验证记录见文末。
**技术：** Flutter Canvas、Riverpod、现有 Dio 与图片生成函数，不新增依赖。
**需求依据：** `docs/daily-check-in-share.md` 及本次性能优化要求。

## 约束

- 仅登录用户可用；图片必须已下载且渲染成功才可展示。
- 自动入口仅在返回学习页检查，不在首次准备完成后补弹；手动未就绪保持 Toast。
- 账号、日期、数据库、语言和二维码地区必须匹配；不能因追求缓存命中而展示其它账号或过期图片。
- 预览、保存、分享使用同一快照；保留生成入口 `generateDailyCheckInShareImage`。
- 不增加固定等待、全局无限缓存或未经测量的 isolate 改造。

- [x] 首次准备与刷新分开：存在有效成品时保留 ready/card，仅更新刷新标记；新图成功后原子替换。

- [x] 账号、日期、数据库及语言/地区变化时立即失效；异步旧代次不得回写。
- [x] 验证返回学习页、前后台切换、刷新失败、换卡失败及跨日/换号。

## 2. 从合成路径移除资料网络等待

文件：同上 provider，`data/share_card_api.dart`；按需要新建 `data/daily_share_asset_cache.dart`，仅负责有界资源缓存和释放。

- [x] 合成读取当前已有的用户资料快照，不 await 正在刷新的 profile future；资料未就绪使用已有占位规则。
- [x] 头像缓存以账号及头像 URL 为键；同键复用 bytes/解码资源与进行中下载；新 URL 后台加载，成功后触发一次更新。
- [x] 头像缺失或下载失败不阻塞首张卡；网络调用具有超时；用户手动重试或资料变化可重试，避免失败后每次统计更新都请求。
- [x] 同一天复用模板及背景；只有首次需要或点击换卡才取模板，不把前台恢复当作重新下载指令。
- [x] Logo、两种二维码和字体复用加载结果；加载失败移除失败 Future 以便重试。
- [x] 验证资料请求永久挂起仍可使用已有成品/生成占位卡；重复统计变化不重复下载头像，换号不复用头像。

## 3. 只在绘制结果变化时重绘

文件：provider、`data/daily_check_in_share_image.dart`、domain 中按需添加明确的输入快照类型；对应测试。

- [x] 建立类型明确的渲染输入比较，使用生成器实际显示的分钟取整结果，而非原始秒数；包含日期、模板、连续天数、昵称、已就绪头像版本、UI/母语和二维码地区。
- [x] 与最后成功输入相同则直接复用 PNG 和预览；周统计、词数等未绘制字段变化不触发重绘。
- [x] 同时只允许一个生成任务；期间输入变化保留最新待生成输入，完成后至多继续处理最新版本，避免丢更新与中间版本排队。
- [x] 任务结束再次检查账号/日期/输入版本，丢弃过期结果；正在展示的弹窗不自动跳图。
- [x] 验证输入完全相同生成次数为 0；秒数变化但显示分钟不变为 0；跨显示分钟只增加必要生成；连续更新最终得到最新值。

## 4. 减少解码与 PNG 生成成本

文件：`data/daily_check_in_share_image.dart`、资源缓存及图片生成测试。

- [x] 解码按实际输出绘制尺寸计算：背景覆盖 1080×1440；头像约 54px；Logo、二维码根据其绘制矩形×1.08取整，保持比例且不超过必要尺寸。
- [x] 相同背景、Logo、二维码、头像复用解码资源；缓存限当前模板和必要固定资源，换卡替换旧背景，不缓存全部历史模板。
- [x] 明确图像所有权：生成期间借用资源，缓存淘汰不得提前 dispose；失效/销毁释放资源，缓存字节和解码图均有界。
- [x] 一次生成保留 PNG 和已渲染预览；打开弹窗不二次解码，不截图，不重复编码；保存/分享直接复用成品。
- [x] 输出渲染图检查排版、透明 Logo 和二维码清晰度。
- [ ] 真机扫描二维码验证可识读性。

## 5. 自动展示去重也不阻塞网络

文件：`providers/daily_check_in_share_presentation_provider.dart`、dialog、`lib/router/main_shell.dart`、偏好测试。

- [x] 自动判断使用当前账号已落地的展示标记；偏好同步由既有后台生命周期执行，不在点击/弹窗路径 await 网络。
- [x] 真正展示后立即写本地标记，后台同步；已知云端标记继续参与去重。
- [x] 接受既有最终一致性：尚未同步到本地的其它设备展示记录可能造成重复，不引入严格全局一次的后端锁。
- [x] 自动跳过日志记录明确原因（未就绪、已展示、其它弹窗、非学习页、后台、未登录），不记录个人信息。
- [x] 验证慢网/离线不阻塞本机展示、同日去重、换号与弹窗互斥。

## 不在本轮增加
